1. Authentication

All requests to /api/v1/* require an active API key supplied in the Authorization HTTP header:

Authorization: Api-Key eip_1a2b3c4d_your_secret_key_here

2. Core Public Endpoints

Method & Path Purpose Required Scope Mode
POST /api/v1/email/verify Verify single email deliverability signals email:verify Synchronous
POST /api/v1/email/verify/bulk Submit email list or CSV/XLSX for bulk verification bulk:write Asynchronous (202)
GET /api/v1/jobs/{id} Get job status and progress counts jobs:read Synchronous
GET /api/v1/jobs/{id}/results Retrieve paginated results for a completed job jobs:read Synchronous
POST /api/v1/finder/company Launch bounded crawl of company website finder:run Asynchronous (202)
POST /api/v1/finder/person Find person by name+company or public URL finder:run Asynchronous (202)
GET /api/v1/usage Get account usage metrics and quotas usage:read Synchronous

3. Quick Code Sample (cURL)

curl -X POST https://api.emailintelligence.local/api/v1/email/verify \
  -H "Authorization: Api-Key $YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"email": "contact@example.com"}'
